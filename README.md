# 矩效 Matrix

矩效是一款面向抖音、小红书、微信视频号和 B 站的 Windows 矩阵账号管理客户端。

## 当前版本

- 正式版：2.7.1
- 当前候选版：2.10.0-rc.12（动态选项读取与个人账号互动工作台，抖音评论/会话只读适配）
- Windows 安装包通过 GitHub Releases 发布
- 源码仓库不保存安装包、数据库、平台登录会话或本机密钥

## 本地开发

环境准备、启动和打包方式请参阅 [本地运行说明.md](./本地运行说明.md)。

## 发布规则

1. 修改 `package.json` 与 `package-lock.json` 中的版本号。
2. 完成类型检查、接口测试、页面测试和四个平台内嵌授权测试。
3. 构建安装包并完成首次启动、升级及重启测试；候选版标记为 prerelease。
4. 提交源码并创建同版本 Git 标签。
5. 将安装包和校验值发布到对应的 GitHub Release。
6. 校验上传结果后，将本地旧候选版安装包移至回收站；保留 GitHub 历史版本和升级测试基线。

尚未取得平台正式接口权限的发布、私信和数据同步能力不会伪装成成功。

## RC11 发布配置说明

### RC12 增量与验收边界

- 音乐、商品、合集新增“选择官方…”入口。先打开本账号的内嵌官方发布编辑器并展开列表，再返回读取。仅支持唯一、明确标注的原生选择框或 ARIA 列表；不使用私有接口、不生成候选数据。候选项绑定账号、页面、一次性令牌和 2 分钟有效期，控件变化时要求重新读取。选择只影响该前台编辑器，不会自动带入其他账号或新建后台任务。
- 评论、私信、粉丝新增个人账号工作台，可读取当前页面中结构可识别的记录，搜索、写本地备注、标记本地待处理/已处理，手动保存或清除快照。快照最多 100 条，按矩效用户、账号、模块隔离；不是全量同步，也不会修改平台已读、已回复、关注状态。无唯一 ID 的记录不按昵称合并、不继承旧备注。
- 回复草稿可以带入内嵌官方页面，由用户核对评论或收件人后确认发送。未增加自动群发、自动获权或绕过验证码。平台网页没有对应功能时仍需官方 APP 或获批接口。
- 新增自动化测试使用隔离页面、账号和数据库。2026-10-12 经用户本人登录后，只读核验抖音作品详情评论及网页消息会话列表，适配已观察到的评论正文和会话预览结构。会话预览不是完整聊天记录；DOM 未提供唯一 ID 时不猜测、不自动选择收件人。
- 真实桌面认证链路与矩效按钮均已核验：当前作品读取 1 条评论，网页消息读取 11 个会话（10 个有预览）；只记录计数，不把用户内容写入测试报告。修正 HTTP 回环地址的 Secure CSRF Cookie 读取问题，保留用户、账号归属和官方会话校验；页面结构无法识别时返回明确中文原因。
- **音乐、商品、合集的真实发布页、真实粉丝列表及评论/私信发送尚未验收**。抖音上传前未呈现动态选择框，用户选择暂不上传，所以不以通用识别器的测试代替真实验收。其他平台未声称完成真实读取适配。读取失败会明确提示，不会用空列表冒充账号无数据。

以下为 RC11 保留能力：

单条视频、批量视频和批量图文共用账号选择弹窗：按分组、标签、平台或常用列表选择，支持搜索、组内选择、已选移除、取消和确定。列表及配置记忆按矩效用户隔离保存在本机；记忆仅包含平台选项，不包含文案、素材、封面句柄和发布时间。

右侧通过平台页签和账号页签切换。单条作品支持独立文案、封面、发布时间及追评；批量作品仍逐篇使用左侧文案，右侧设置用于该账号的整批作品。同平台合并开关只影响开启后的修改，不改动已提交账号。

抖音、小红书、B站的字段参考用户提供的界面；视频号补充短标题、描述、话题、位置、合集、活动、链接、商品、声明、互动权限及时间配置。字段出现不代表当前账号具备该能力，平台可能因作品类型、地区、版本和权限显示不同项目。当前配置长度上限用于提交前提示，不会静默截断文案。

自动同步边界：

- 标题、简介、可见范围、分类和创作类型：仅在官方编辑器唯一识别到对应控件、匹配到有效选项后填入。
- 原创、互动、水印等开关：仅匹配唯一、可见且标签完全一致的官方复选框；无法确认则停下。
- 音乐、活动、商品、合集、位置、@用户及声明等动态选择：保存配置要求，任务进入“需要处理”，由用户在内嵌官方页面选择。不会把纯文本当成已挂载商品或已关联用户。
- 封面裁剪、官方定时和最终提交仍需核对。追评当前生成独立待办，不代表评论已发出。“不弹验证”不可用，不能跳过平台验证。

开放接口与网页配置不是一回事：[抖音创建视频文档](https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-video/video-create)要求对应应用能力及用户授权；[B站视频编辑文档](https://open.bilibili.com/doc/4/ddfbe54d-b4ab-340e-c698-933b9a3c619c)也有相应授权范围与字段要求。本版不声称已取得这些接口权限。

回归测试使用一次性数据库、用户目录和模拟官方表单，包含配置隔离、分页、完整长页截图、拖拽、后台队列、四个平台会话及打包升级。测试不等于四个平台真实发布验收，未对用户的真实作品执行上传、评论或删除。
