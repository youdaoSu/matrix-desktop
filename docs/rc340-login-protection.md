# RC340 登录兼容与频繁访问保护

实机复现抖音扫码确认后，官网二维码查询返回 HTTP 200、业务 error_code 7 及“访问太频繁，请稍后再试”。此前只依靠 HTTP 429 和特定 toast 样式会漏判；本次观察到确认后四次查询即出现拒绝，不能据此归因于远效后台循环访问登录接口。

绑定页增加只读 DOM 观察，识别短暂、任意样式及官方子页面中的频繁访问提示。触发后持久化平台保护间隔，卸载此绑定文档，停止官网二维码 SDK 的轮询，保留分区 Cookie 与存储。用户内容、隐藏提示和已结束绑定的迟到结果排除；普通账号编辑页不加入绑定观察。

主窗口显示保护至何时，并限制保护期间的刷新及导航。到期需手动重新打开官网，软件不自动重试登录；软件保护结束不保证平台限制解除。发布前的本人身份校验保持执行。

浏览器标识统一采用当前实际 Chromium 与操作系统信息，去除中文产品名称、远效 RC 版本及 Electron 产品标识，避免非法 HTTP 头字符与每次更新带来的应用版本变化。不替换内核版本、设备、代理、账号或登录资料；未修改官网 SDK、验证码或 fetch/XHR。

使用真实 Electron、隔离 HTTPS 响应与合成 Cookie 验证 HTTP 200 拒绝经官网提示触发暂停、短暂提示、子页面、轮询停止、Cookie 保留、编辑页不受影响和解绑后观察释放。普通浏览器重新扫码成功已经由用户确认；兼容标识对照尚无成功扫码记录，不能宣称本次已解决平台登录限制。
