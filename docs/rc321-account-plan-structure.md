# RC321 账号与自动化计划分工

## 用户入口

- **账号管理 → 主账号与协作分工**：平台与账号名称、独立账号/主账号/协作账号、所属同平台主账号、官网连接和监听授权。账号工作区侧栏也提供入口。
- **粉丝互动 → 自动私信/自动评论 → 新建计划**：选择自动完成的事情，再配置账号、触发条件、文案、延迟和额度。批量任务保留人工批次入口，另有进入同一配置器的新建自动化计划入口。
- **计划列表**：保留原自动回复规则；私信列表包含新增关注规则、评论转私信规则、当前本人粉丝分批计划和关键词协作规则。分页与筛选统一计算，不重复发送历史记录。
- **文案工具**：保留原模板和本地预演；选用文案进入新建计划填写草稿，只有在计划表单保存后才创建规则。草稿默认停用。

## 配置范围

账号分工与官网连接只有账号管理一份配置界面。旧连接深链接给出新入口，不保留重复编辑表单。

计划配置器复用 `RuleEditor`、`OperationsOwnFans`、`OperationsKeywordRoutes`，不复制发送器和存储。全局发送时段、尝试额度以及同账号/同渠道模式仍沿用原有范围，在计划内折叠区明确标注“所有计划共用”，本次没有伪造独立计划额度。

账号设置页只在进入/刷新/保存时读取有界快照，每类历史最多1项；不挂载私信与评论历史 hooks，不创建轮询。账号租户变更后旧异步响应不得显示。

## 兼容与验证

不变更现有规则 ID、业务数据格式、发送额度计算、身份核对、去重和回执规则。仅导航、打开表单、选择类型、查看状态不启用或发送任务。
