## 已实现

- 任务记录 → 更多：取消原追评置顶、删除原追评；明确展示账号、作品、原评论 ID 和正文，需单独确认。
- 主进程再次验证原发布回执、账号绑定会话、官网本人 UID、作品归属及原评论 ID/正文/一级评论归属。确认弹窗的 ID 或正文与回执不同则拒绝。
- 取消置顶只针对原 rpid；当前为另一条置顶时不写入。删除仅使用原 rpid，不匹配同名或同文案的新评论。
- 删除已获官方 code=0/12022 回执才记已删除；查不到评论、-404、网络超时不能冒充删除成功。
- 写入前持久化未知管理结果。未知结果只允许只读核对，重复请求、重启和其他写操作均不能重复删除或重发。
- 评论删除与取消置顶不回退原作品/评论的历史发表成功状态，不自动重发视频或评论。
- 原评论已删除但用户另发并置顶的新评论不会自动关联。原回执不能管理那个新 ID。
