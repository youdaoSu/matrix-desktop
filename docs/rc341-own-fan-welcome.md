# RC341 未私信粉丝欢迎语

入口：粉丝互动 → 自动私信 → 新建计划 → 给未联系粉丝发欢迎语（抖音）。选择本人抖音主账号，填写欢迎语、每批人数、同批次逐条间隔及不同批次间隔，核对名单后开始。默认每批 10 人、逐条 30 秒、批间 300 秒；每批 1–50 人，逐条至少 5 秒，原有平台限制与共享发送额度继续生效。

默认核对全部已同步粉丝，使用现有原生粉丝名单和完整可读私信历史，每页核对 50 人，最多覆盖现有目录支持的 50000 人。名单尚未完整同步时提示先完成账号管理里的全部粉丝同步；核对期间名单变化则停止，不把部分缓存或混合分页称为全部。历史不完整、已有发出消息、待处理任务及已有处理记录均排除。旧的分段核对方式仍可选。

固定名单单独加密保存，进度和结果单独持久化，按批次自动继续；名单预览按 50 人分页，确认总人数对应完整固定名单。暂停或重启保留进度，重启不会自动发送。

默认勾选“明确发送失败后，尝试普通关注再发送一次”，启动预览明确展示这项行为。仅原账号的明确未发送失败符合条件：发送前一般任务失败，或带平台拒绝证据的接收人限制；额度、登录、身份冲突、超时和未知投递结果不会触发关注补发。

普通关注在专用的隐藏官网主页核对发送账号、粉丝数字 UID 与主页身份，先持久领取再点击一次正常关注按钮。私密资料需申请、页面已提示申请好友或关注后出现申请弹窗时，不提交申请，不再发欢迎语，持久记录并移出队列。普通关注有确定结果后，按原逐条间隔建立一次关联原失败证据的补发任务；原发送领取记录、正文、账号、粉丝和失败证据不重置。补发失败或关注结果不明时暂停，不重复尝试。

成功和需申请好友按实际发送账号的平台身份与粉丝 UID 持久排除，修改欢迎语、重建计划、重启或同账号重新绑定不清空标记。历史删除或平台不提供的内容无法据此证明从未联系。

验证使用隔离工作区、真实 React、真实 Electron 官方域名协议夹具、原生页面桥接与合成粉丝。覆盖 1001 位完整扫描、名单变更拒绝、分页预览、批内/批间间隔、重启恢复、原失败回执关联、私密资料申请排除、申请弹窗不提交、发送账号错误拒绝、排除记录重开与辅助页面释放。没有向真实粉丝测试发送或关注。
