# RC322 评论管理单条评论

入口：粉丝互动 → 评论管理。抖音可选择当前绑定账号已读取的作品，点击“一键评论”；抖音、小红书、B站已核实发布任务可点击“前往评论管理”，自动关联原账号与作品。小红书和B站普通历史作品没有完整官网编号时不会按标题猜测，需由原发布任务进入。

本轮为单账号、单作品、人工填写正文并预览确认的发送流程。发送账号固定为作品所属账号。不增加账号组轮发、随机文案或一键点赞。账号运营既有历史记录保留。

复用既有加密评论队列、官网适配器与回执核对：主窗口鉴权、账号/会话/作品原始回执核验、提交前持久化防重复记录、明确评论ID才报成功。未知结果保留原尝试，不自动重发。同一账号同一作品已有提交记录时不重复发送。

从任务进入后单独解析原发布回执，实际作品编号用于评论筛选；切换账号、解绑重绑、注销或切换作品后的迟到结果不覆盖当前选择。发送已受理后即使紧随的状态读取失败，也保留进行中记录并继续有界间隔读取。未运行时无后台轮询。

验收使用合成数据与隔离窗口，不向真实平台发送评论。本文件是候选说明，安装与最终核验以 E:\远效\开发记录\rc322-20261103 的交付回执为准。
