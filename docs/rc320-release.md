# 远效 2.10.0-rc.320

2026-11-02。此提交汇总自仓库 RC15 基线以来的本地迭代源码；安装包未通过本次源码同步发布。

## 本次新增

- 已核实发布成功的作品可选择同平台账号与评论集，生成固定随机预览，再串行执行一键评论。
- 本人抖音账号可从缓存粉丝中核对尚无已知发出消息的对象，配置每批人数、逐条间隔和批间间隔。首批确认开始后按计划继续后续批次。
- 每轮最多核对 500 位缓存粉丝，每批 1–50 位；默认每批 10 位、逐条 30 秒、批间 300 秒。
- 切换页面和暂停保留进度，重启恢复为暂停；明确平台回执才计成功，结果不明时停止，避免重复发送。

## 累计更新范围

包含发布上传/表单/结果回读与任务记录、B站追评置顶管理、抖音粉丝分页及头像、私信历史和昵称关联、账号运营与关键词任务、存档与后台采集性能、远效品牌及界面调整。各平台能力仍取决于当前官网行为和账号状态。

## 验证

RC320 的 242 组完整源码回归通过；实际安装包的 96 组隔离检查通过，39 个物理 worker 依赖逐文件核对。安装后业务文件与原密钥校验一致。

测试使用合成账号、消息和隔离目录。本轮未向真实账号发表评论或私信，不能将隔离测试当作各平台真实端到端发送验收。

## 使用边界

本人粉丝分批私信入口：粉丝互动 → 自动私信／批量任务 → 粉丝分批私信。需先配置本人抖音主账号，原生私信连接就绪且可读取历史完整。

历史不完整、身份冲突和已有发出记录的对象不会进入发送名单；平台删除或不提供的历史不能证明“从未联系”。不自动扩大本次接收人集合。原有全局时段、额度及平台验证继续生效。

## 开发与构建

- 锁定依赖见 `package-lock.json`，桌面打包配置见 `package.json`。
- 完整隔离回归：在源码根目录运行 `node scripts/qa-publish-stability.cjs`。
- Windows 桌面构建入口：`scripts/build-desktop.ps1`。构建脚本需要对应 Node、Electron、WebView2 宿主及内置数据库资源；源码同步不附带已安装运行库或用户配置。
- 安装、升级与真实平台发送应分别验证，不使用真实账号发送来代替单元和隔离回归。
